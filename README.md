# College Helpdesk Chatbot — Netlify version

Static website version of the beginner rule-based college chatbot. The browser app uses JavaScript `if-else` conditions and keyword matching; the separate Python terminal file remains available for the assignment requirement.

## Test locally
Open `index.html` in a modern browser.

## Publish on Netlify
1. Sign in to Netlify.
2. Open the manual deploy / drag-and-drop page: https://app.netlify.com/drop
3. Drag the **college-chatbot-netlify folder** (or a ZIP containing the files) into the drop area.
4. Wait for the deploy to finish, then open the generated `*.netlify.app` URL.
5. Test the greeting, fees, library, and exam buttons.

This is a static demo and does not connect to live GMIU systems.
